# 卡牌量化評分報告

分數 = 效果價值（能量單位）× 關鍵字係數 ÷ 有效費用。百分位 = 在原版同稀有度卡中的位置。
confidence：auto 純數值；partial 有額外邏輯（分數可能低估）；manual 無法自動評分。

## 從原版校準的係數

假設原版多數卡強度相近，反推費用曲線與關鍵字代價（非能力牌、無上述關鍵字的卡）。

| 費用 | 有效費用 | 樣本數 |
|---|---|---|
| 0 | 0.84 | 27 |
| 1 | 1.00 | 77 |
| 2 | 1.80 | 22 |
| 3+ | 2.70 | 7 |

| 關鍵字 | 價值係數 | 原版樣本數 |
|---|---|---|
| Exhaust | ×0.85 | 23 |
| Ethereal | ×0.85 | 4 |
| Retain | ×1.10 | 5 |
| Innate | ×1.15 | 5 |

係數 < 1 表示原版會給帶該關鍵字的卡更強的效果作為補償，因此它是代價；能力牌不套用消耗係數。
